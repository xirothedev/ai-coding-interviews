# ADR 0002 — Three difficulty tiers mapped to L3–L6+

## Status

Accepted.

## Context

Need a simple, defensible calibration for HR. Candidates range from junior to staff.

## Decision

Three tiers: Easy (30–45 min, L3–L4), Medium (45–60 min, L4–L5, Meta standard bar), Hard (60–75 min, L5–L6+, Senior/Staff).

## Consequences

- Calibration claims in docs/CONTRIBUTING must match actual case file/bug counts (see audit).
- Adding a case requires choosing one tier and following `templates/en/CASE_TEMPLATE.md`.
