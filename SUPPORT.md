# Support & Usage Guide

Welcome to the **AI Coding Interviews** knowledge base! Whether you are an **HR Specialist / Technical Recruiter**, an **Engineering Manager / Interviewer**, or a **Software Engineer** practicing for AI-enabled coding interviews, here is where to start.

---

## Where to Start by Role

### For HR Teams & Technical Interviewers

1. Read **[The 7 Evaluation Criteria](docs/en/01-THE-7-EVALUATION-CRITERIA.md)** to understand what modern AI-enabled interviews measure beyond syntax generation.
2. Read the **[HR & Interviewer Runbook](docs/en/03-HR-AND-INTERVIEWER-RUNBOOK.md)** for the 60-minute interview structure, workspace preparation instructions (including stripping `.git` history), and behavioral grading rubrics.
3. Copy the **[Candidate Scorecard Template](templates/en/SCORECARD_TEMPLATE.md)** to standardize debriefs across your hiring panel.
4. Pick a case matching your target role and seniority from:
   - **[Easy Cases (10 Cases)](cases/en/easy/README.md)** — Junior / Mid-level or 30–45 minute warm-up screens.
   - **[Medium Cases (10 Cases)](cases/en/medium/README.md)** — Standard 45–60 minute SWE loop (Meta / Canva / Stripe bar).
   - **[Hard Cases (10 Cases)](cases/en/hard/README.md)** — Senior / Staff 60–75 minute deep-dive sessions.

### For Employees & Candidates Practicing

1. Read the **[Employee Mindset & Prompt Playbook](docs/en/02-EMPLOYEE-MINDSET-AND-PROMPT-PLAYBOOK.md)** to master the **Divide-and-Conquer** control mindset and the **`Understand → Plan → Prompt → Review → Test`** loop.
2. Bookmark the pre-written prompt templates in that playbook so you can quickly map unfamiliar codebases and trace execution flows before editing code.
3. Clone one of the linked GitHub repositories in **[Easy](cases/en/easy/README.md)**, **[Medium](cases/en/medium/README.md)**, or **[Hard](cases/en/hard/README.md)**, read only the **Candidate Instructions (Checkpoints 1–4)** first, and time yourself for 60 minutes before checking the **AI Trap Analysis** and **Interviewer Rubric**.

## Getting Help & Asking Questions

- **Found a broken GitHub repository link or outdated commit SHA?**  
  Open an issue using the [Broken Link / Repo Report](.github/ISSUE_TEMPLATE/broken_link_or_repo.yml).
- **Want to propose a new interview case or add a language variant?**  
  See [CONTRIBUTING.md](CONTRIBUTING.md) and open a [New Interview Case Proposal](.github/ISSUE_TEMPLATE/new_interview_case.yml).
- **Discovered a new LLM failure mode ("AI Trap") during a real interview or practice run?**  
  Share it with the community via the [AI Trap / Rubric Update](.github/ISSUE_TEMPLATE/ai_trap_or_rubric_update.yml) template!
